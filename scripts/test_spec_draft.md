## ✅ 4. 事前準備手順

### 4-1. テスト開始前の準備

S13（スポット新規追加）が最初のテストのため、事前にスポットデータを準備する必要はありません。
ただし、テスト開始前に `register@example.com` が Supabase に登録済みであることを以下の手順で確認してください。

1. ブラウザで https://supabase.com を開く
2. 「Sign In」をクリックしてログインする
3. 該当プロジェクトをクリックして開く
4. 左メニューの「Authentication」をクリックする
5. 「Users」タブをクリックする
6. `register@example.com` が一覧に表示されていることを確認する

### 4-2. テスト後のクリーンアップ（後片付け）

全テスト完了後に以下の手順でテストデータを削除してください。再テスト時は S13 から始めてください。

※ テスト碑（修正）は TC-S10-05 で削除済みのため後片付け不要です。

**【アプリから削除する】**

1. 管理者アカウントでログインして管理ページ（/admin）を開く
2. スポット管理タブで「テスト碑（必須）」の行の「削除」をタップする
3. 確認ダイアログで「削除する」をタップする
4. 同様の手順で「テスト申請碑B」も削除する

**【Supabase から手動削除する（テスト申請碑A：却下済みのためアプリから削除不可）】**

1. ブラウザで https://supabase.com を開く
2. 「Sign In」をクリックしてログインする
3. 該当プロジェクトをクリックして開く
4. 左メニューの「Table Editor」をクリックする
5. テーブル一覧から「monuments」をクリックする
6. 「テスト申請碑A」の行を探す
7. 該当行の左端のチェックボックスにチェックを入れる
8. 上部の「Delete rows」をクリックする
9. 確認ダイアログで「Delete」をクリックする
10. 「テスト申請碑A」の行が消えていることを確認する
